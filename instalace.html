Kontroluji…

Chrome hlásí „už nainstalováno“, protože stará ikona má scope na celý web /Rotenso_Windmi/ — včetně této nové cesty /w3/.

Bez smazání staré ikony nejde nainstalovat znovu. Žádná nová URL v tom samém repu to neobejde.

Android — odinstalace

  1. Zavři Windmi úplně (odeber z recent / přehledu aplikací).
  2. Dlouze podrž ikonu Windmi na ploše → Informace o aplikaci / Odinstalovat (nebo Nastavení → Aplikace → Windmi / Chrome → Odinstalovat).
  3. V Chrome otevři znovu tuto stránku (z odkazu níž, ne z ikony).
  4. Menu Chrome ⋮ → Nainstalovat aplikaci / Přidat na plochu.

Počítač

  1. Do adresního řádku: chrome://apps → odstraň Windmi.
  2. Ještě: Nastavení Chrome → Soukromí → Smazat data webu pro milnek5792.github.io.
  3. Obnov tuto stránku a nainstaluj.
